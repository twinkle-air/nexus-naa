# 方法边界

## 本 Skill 可以做什么

- 将受支持的谱文件归一化为 `channel,counts`；
- 检查连续通道、有限非负计数与基础统计；
- 使用可追溯参考点拟合线性能量标定；
- 运行确定性寻峰、实验性 SNIP 本底和有限的相邻双峰拟合；
- 查询固定核数据快照并形成分级核素候选；
- 验证证据链后生成结构化结果和 HTML 报告。

## 本 Skill 不能证明什么

- 数据库命中或 `supported` 不等同于确认检出；
- 两点零残差不证明标定准确，也不验证非线性或漂移；
- 未知谱不能由文件名或两个未知峰反推唯一标定；
- 当前局部 Gaussian 双峰拟合不是通用峰形解卷积；
- 缺少效率、时间、几何、质量、空白和修正时不能给出活度或元素含量；
- 当前固定数据快照不是完整、实时核数据库；
- 输出不能独立用于医疗、安全、监管或商业检测决策。

## 宿主模型的职责

宿主模型只能识别目标、选择工具、提出必要问题并解释已验证证据。峰值、标定系数、核数据、状态和证据 ID 必须来自工具。工具矛盾、证据不可追溯或验证失败时，模型必须停止或降低结论。
