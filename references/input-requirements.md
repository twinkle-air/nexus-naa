# 最低输入与允许输出

| 目标 | 最低输入 | 阻断条件 | 信息不足时最多输出 |
| --- | --- | --- | --- |
| 查看谱图/QC | 通道—计数数据 | 无法解析、负计数、重复或乱序通道 | 格式错误与修复建议 |
| 寻峰 | 连续通道、有限非负计数 | 通道间断；不得自动补零 | QC 和谱图，不输出峰表 |
| 能量标定 | 至少两个可追溯参考点 | 少于两点、重复通道、非正斜率 | 说明缺失点，不猜测 |
| 单能量查询 | 能量和容差 | 能量或容差无效 | 固定数据库候选，不是测量结论 |
| 核素候选 | 已标定谱、容差、峰表 | 无标定、目标峰为标定外推、工具矛盾 | 峰表或 `insufficient_evidence` |
| NAA 定性解释 | 上述内容，以及照射、冷却、计数和背景信息 | 缺关键实验背景 | 仅核素候选，不推断元素来源或反应路径 |
| 活度/元素定量 | 效率刻度、活/实时间、几何、质量、空白与必要修正 | 任一必要输入缺失 | 明确拒绝定量；列出所缺输入 |

信息缺失时一次只问最优先、会改变下一步工具选择的问题。优先顺序：可解析谱 → 连续通道 → 可靠标定 → 容差 → 实验背景 → 定量参数。不会阻断当前较低层目标的信息应作为 `missing_information` 保留，不能被模型补写。
