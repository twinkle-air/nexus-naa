# 候选证据与停止规则

## 谱线状态

- `observed`：存在未被当前候选重复占用、且在容差内的观测峰。
- `expected_but_not_observed`：只有外部可观测性输入明确表明应可见时才能使用。
- `below_observability`：只有确定性工具已给出低于观测能力的判断时才能使用。
- `outside_range`：参考线超出本次测量能区。
- `overlapped`：峰参与重叠拟合或确定性重叠检查。
- `not_assessable`：缺效率、几何、探测限或背景信息，无法判断未见谱线。默认采用这一保守状态。

## 核素状态

- `supported`：至少两条不同参考线对应独立观测证据，均在标定参考范围内，且无阻断性矛盾。
- `tentative`：只有一条非湮没参考线或支持仍不完整。
- `conflicting`：明确应可见的伴随线缺失，或证据相互冲突。
- `insufficient_evidence`：无可靠标定、外推、仅 511 keV、来源不足或证据不可追溯。

## 候选召回与支持资格

用户容差用于尽量保留可审查候选；它不直接等于支持阈值。逐线支持窗采用 `min(用户容差, FWHM_keV/2 + 标定 RMSE)`。该公式是项目工程规则，不是通用计量标准。缺少峰宽、标定 RMSE 或参考能区时，候选保留，但不可贡献支持。

逃逸峰与可能求和峰的能量巧合筛查也使用上述峰宽相关窗口，而非直接采用宽松的候选召回容差。能量巧合只触发待复核警示，不能单凭它断言真符合求和；缺几何、效率等条件时应保持该限制。

支持线必须同时满足：位于参考标定能区、残差在支持窗内、不是 511 keV 非唯一线、未被逃逸峰/求和峰/重叠解释阻断、没有更接近的异核素参考线，并且同一观测峰只计一次。逐线读取 `supportEligible`、`supportWindowKeV`、`independenceStatus` 和 `supportExclusionReasons`；不得仅看分数。

任何数据库分数都不是概率。排除支持并不等于证明核素不存在；候选仍应保留供人工复核。缺少能量相关效率、几何、自吸收与统计不确定度时，不比较峰面积与发射概率的比例来提升结论。
