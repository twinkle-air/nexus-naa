# 能量标定规则

- 只接受用户、仪器元数据或与本次实验绑定的标准源参考点；禁止从未知谱或文件名猜点。
- 两点是线性拟合的数学最低要求，但其零残差不能独立验证准确性，状态为 `two_point_unverified`。
- 三至四点为 `limited_multipoint`；五点以上为 `multipoint`。点数不是充分条件，仍须检查残差、峰形、漂移和能区覆盖。
- 保存 `referenceRangeChannel` 与 `referenceRangeKeV`。参考范围之外属于外推，不得输出 `supported`。
- 511 keV 湮没线可以在已知标准源条件下作为标定参考，但不能唯一识别核素。
- 当前工具只实现线性标定；若残差显示非线性，不擅自换高阶模型，应停止并要求适当的仪器标定。

依据：IAEA TRS 295 将准确能量标定列为 γ 发射体识别的必要条件；IAEA TRS 454 建议多个精确已知峰覆盖目标能区，并在实验室程序中使用至少五个能量点。
