# 核数据使用政策

1. 默认只使用 `data/nuclear-lines.json` 的固定、可追溯本地快照；网络中断时分析仍可复现。
2. 每条记录保留数据集、记录 ID、发射核素、能量、发射概率、来源、页面或原始记录和提取日期。
3. 实际发射核素、母体核素和间接指示核素必须区分；只有平衡条件成立时才能说明代理关系。
4. 数据库搜索结果是候选集合，不是样品检出。来源冲突进入审查记录，不静默选择。
5. ENSDF API 当前为 public beta，只用于建立候选导入批次。导入必须固定响应、哈希和来源，并通过 `scripts/import-ensdf.mjs` 的逐条资格审查后才能合并。
6. 实时数据不可用时不得用模型记忆补充能量或发射概率；使用本地库或明确停止。

数据库覆盖范围和逐条资格见 `data/NUCLEAR_DATA.md`、`data/SUPPLIED_DATA_AUDIT.md` 与 `docs/ENSDF_PIPELINE.md`。
