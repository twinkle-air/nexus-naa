使用指南
快速开始
  1. 选择或拖入 CSV、TXT、DAT、SPE、XLS 或 XLSX 能谱。
  2. 核对通道数、总计数和质量检查警告。
  3. 执行寻峰，检查弱峰显著性与峰形。
  4. 手动输入标定点，或选择已知标准源自动填入后人工确认。
  5. 匹配核素候选并导出 CSV、JSON 或完整 HTML 报告。
导入与检查
文本文件应包含 channel、counts 两列；SPE 读取 $DATA 区段。Excel 不可用时系统自动使用只读解析器。警告不会被静默忽略。
寻峰与标定
局部显著性模式更利于保留弱峰，但降低 σ 阈值会增加假峰。自动标定只生成建议，不会替你确认参考线。
候选与报告
数据库命中仅表示能量相容。应结合伴随峰、效率、几何、照射和冷却条件判断；“未命中”不等于排除。
智能体接入
网页助手支持离线规则、手动真实模型验证和多个 API；Codex、Claude Code 等宿主可通过 MCP 调用同一套科学工具。
