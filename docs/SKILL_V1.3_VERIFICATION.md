# Skill V1.3 完整性与实用性核对

V1.3 处理 V1.2 复核中剩余的主要问题：Eu-152 谱在宽容差下出现非标签 `supported`、评测没有把该结果纳入失败门槛，以及 32 位 FNV 指纹不适合作长期归档标识。

| 改进 | 实现 | 可执行证据 |
| --- | --- | --- |
| 候选与支持分离 | 宽容差内候选保留；支持窗另用 `min(tolerance, FWHM/2 + RMSE)` | `tests/core.test.js` |
| 谱线独立性 | 排除标定外推、511 keV、未解决逃逸/求和/重叠、更接近异核素线和同峰重复计数 | 核心与真实谱回归 |
| 排除原因可追踪 | 谱线与伴随线输出支持资格、支持窗、独立性状态和原因 | JSON Schema 与全字段重建验证 |
| 分析身份 | 规范化 JSON 使用 SHA-256 | FIPS `abc` 标准向量、键序稳定与变更敏感测试 |
| 质量门槛 | 非标签支持、无依据确定结论、Top-1/Top-3 退化均使评测失败 | `tests/fixtures/identification-quality-policy.json` |
| 评测资格 | 每个样本记录标定方式、类别、真值资格和准确率资格 | `identification-evaluation-cases.json` |

当前三份参考谱全部属于标签辅助标定，不能用于估计盲识别准确率。待补的验证类别包括独立校准、空白、目标缺失负样本、认证混合谱、低计数和干扰真值谱。宿主行为评测仍是确定性策略夹具，未冒充真实多模型运行结果。
