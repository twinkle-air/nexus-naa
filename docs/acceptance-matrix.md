## 本次修复
修正文档版本；文件原始字节 SHA-256；科学计数法解析；负斜率拒绝；间断通道寻峰保护；面积改用原始计数有符号积分；半突出度宽度明确为初估；禁止峰自我伴随支持；未寻峰与零峰区分；零峰导出和非法容差检查。
核数据从笼统数据库主页引用改成固定报告页；Evidence 增加参考记录 ID、页码与 URL；旧未核实快照保留但不参与计算。

## 实际证据与限制
浏览器合成谱：1600 通道、总计数 23040；两个候选峰约 1173.22、1332.47 keV，Co-60 伴随支持，来源 PDF 第 117 页。仅验证算法链路，不是实验检出。
公开 Cs-137 未标定分析执行 QC/寻峰，候选匹配未执行。下载 HTML 已检查谱 SVG、哈希和分析内容。
HTTP 运行检查：静态模块返回 200；模型不可用返回 503，并提示检查服务或切换离线助手；外部 Origin 请求返回 403。
当前对话模型对“分析这张谱”的真实输出 `{"action":"analyze"}` 已通过手动验证入口并执行完整工具链；该方式验证推理与契约，但应用无法认证粘贴来源。四种自动适配器均用模拟的各厂商响应结构测试；未配置真实 API 密钥，也没有安装 Ollama，故不能宣称自动 API 端到端推理已验收。
弱峰模式采用局部泊松显著性，尚未建立实验基准集检出率/误报率验证，也未复现 SNIP/小波算法；未包含重叠峰拟合、不确定度、效率刻度、NAA 定量与完整数据服务。

## 跨宿主补充

模型 API 适配器用于网页助手直接调用模型；MCP 服务器用于 Codex、Claude Code 等宿主调用科学工具，二者职责分离。MCP 按 2025-06-18 stdio JSON-RPC 实现，工具失败以 `isError: true` 返回，使宿主可以修正参数。统一导入工具支持文本谱与Base64表格字节。HTTP开发服务仅绑定回环地址，不具备公网部署所需身份验证。

## 输入格式补充

SPE 解析器严格验证 `$DATA:` 的通道数量，截断数据会拒绝。Windows Excel 转换器已用用户提供的旧版 XLS 和临时生成的 XLSX 实测；Excel 以只读和禁用宏方式运行，临时目录在成功或失败后均清理。当前方案依赖本机 Microsoft Excel，不属于跨平台实现。
