# 标准谱三系统识别对照

V1.3 对用户提供的 Co-60、Eu-152 和 Ba-133/Cs-137 三份标准谱运行可重现对照：最近能量线基线、谱线＋伴随峰基线、完整核素证据＋支持资格与停止规则。

```bash
node scripts/evaluate-identification.mjs
```

统一使用 SNIP LLS、8σ、平滑窗 5、最小峰距 8，并扫描 0.5、1、2 和 3 keV 候选容差。标定使用文件已知标准源标签生成的参考配对；三份数据均标记为 `accuracyEligible: false`。下列比率是固定回归集的“参考标签保留率”，不是盲识别准确率。

2026-09-22 的 12 个谱—容差组合结果：

| 系统 | Top-1 参考保留 | 平均 Top-3 参考召回 | 平均正确保留率 | 非标签 `supported` | 无充分依据的确定性结论 | 平均未解释峰率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 最近能量 | 100% | 100% | 100% | 0 | 0 | 53.47% |
| 谱线＋伴随峰（V1.2 宽容差基线） | 100% | 100% | 83.33% | 2 | 0 | 53.47% |
| 完整证据 | 100% | 100% | 83.33% | 0 | 0 | 53.47% |

V1.2 暴露的 Eu-152 谱中 Eu-154 非标签 `supported` 已在 2/3 keV 容差下消除。Eu-154 仍作为候选保留，并附支持窗、竞争谱线或不可独立使用等排除原因；这避免把“未支持”误写成“不存在”。Ba-133/Cs-137 混合谱中，Cs-137 位于 Ba-133 辅助标定参考能区外，因而保守降级，这也是平均正确保留率为 83.33% 的原因。

## Ba-133 混合谱逐线复核

此前在 2–3 keV 候选容差下，Ba-133 从 `supported` 降为 `tentative`。复查发现，候选召回容差也被用来判断求和峰巧合，使 302.835 与 356.024 keV 两条匹配线被错误地排除：对应的观测峰求和与目标峰分别相差约 1.034 和 1.200 keV，已大于各自约 0.811 和 0.824 keV 的峰宽相关支持窗。现在逃逸峰和求和峰巧合检查使用 `min(候选容差, FWHM/2 + 标定 RMSE)`，与逐线支持资格窗口一致；这是本项目的保守工程筛查规则，并非证明某峰是否确属求和峰的物理判据。

| Ba-133 参考线 (keV) | 观测峰 (keV) | 匹配残差 (keV) | 2–3 keV 时支持窗 (keV) | 当前资格 |
| ---: | ---: | ---: | ---: | --- |
| 276.3989 | 276.4080 | +0.0091 | 0.8081 | 可独立支持 |
| 302.8508 | 302.8348 | −0.0160 | 0.8105 | 可独立支持 |
| 356.0129 | 356.0242 | +0.0113 | 0.8243 | 可独立支持 |
| 383.8485 | 383.8440 | −0.0045 | 0.8202 | 仍标记 `UNRESOLVED_PEAK_ARTIFACT`，不计入支持 |

383.844 keV 峰与观测到的约 80.816 + 302.835 keV 峰之和相差约 0.193 keV，求和可能性尚未排除。因此四档候选容差下 Ba-133 均为 `supported`，但只由前三条合格的不同谱线提供支持；不能把第四条警示峰解释成已证实的独立证据。评估脚本输出 `referenceLineAudit` 供逐条重现。此混合谱仍采用已知 Ba-133 标签辅助标定，不能据此估计盲识别准确率。

质量策略位于 [`tests/fixtures/identification-quality-policy.json`](../tests/fixtures/identification-quality-policy.json)。完整证据系统必须同时满足：非标签 `supported` 为 0、无充分依据的确定性结论为 0、Top-1 参考保留为 100%、平均 Top-3 参考召回为 100%；否则脚本以非零状态退出。

当前覆盖缺口被机器可读地列在评测计划中：独立校准、未知标签盲测、空白谱、不含目标核素的负样本、有认证真值的混合谱、低计数谱与干扰真值谱。因此，本结果只能证明固定谱回归与质量门槛通过，不能证明普适识别准确率或误报率。
