# 用户标准谱回归结果

验证日期：2026-09-06。命令：`node scripts/validate-reference-spectra.mjs`。输入文件及SHA-256见 `data/REFERENCE_SPECTRA.md`。

统一参数：平滑窗口5、最小峰距8通道；原局部模式4σ；SNIP模式采用LLS变换、递减窗口24通道和8σ。先用原局部模式及已知标准源生成标定建议，再以参考线±2 keV检查是否存在候选峰。

|谱文件|参考核素|原局部模式候选数|SNIP 8σ候选数|SNIP检出主要参考线|
|---|---:|---:|---:|---:|

|Eu-152.xls|Eu-152|77|48|13/14|
|Ba-133_Cs-137.xls|Ba-133|16|10|4/4|

Eu-152未通过8σ的库内参考线为1089.737 keV，发射概率1.731%。降低阈值可能找回该线，但会增加伪峰，故没有为追求14/14而调整默认标准。Ba-133/Cs-137混合谱在Ba-133标定下也观察到Cs-137约661.657 keV峰；该谱的Ba-133参考线只覆盖约107.45 keV，661.657 keV属于较远外推，只作为存在性检查，不作为高精度标定证明。

这些结果证明三份文件中已知主要峰在当前流程中的可检出性，不证明每个自动候选都是真峰，也不提供峰面积、效率或活度真值。双Gaussian拟合使用合成已知双峰做参数回归；三份实测表格没有逐个重叠峰的独立真值，因此仅能检查拟合能否执行，不能宣称实测参数准确。
