# V1.0 分析方法与边界

V1.0 是软件发布与登记版本号；以下科学方法沿用 v0.4 阶段的功能范围，并不表示已完成经验证的元素定量。分析 JSON 的格式版本仍为 0.4，以保持旧文件兼容。
## 输入与共享状态
CSV/TXT/DAT 使用严格两列解析；SPE 读取 `$DATA:` 声明的起止通道，并要求计数数量完全匹配。XLS/XLSX 优先由本机 Excel 以禁用宏、禁止更新链接、只读方式打开；Excel COM 不可用时自动回退到项目固定的 xlrd/openpyxl 只读解析器。两条路径都选择数值行最多的工作表前两列。表格元数据行会被忽略；自动选列不适合多组二维数据并列的复杂工作簿，导入后必须核对通道数、范围和总计数。

一份当前谱同时供 QC、图形、寻峰、标定、候选和报告使用。峰、标定、匹配是派生状态，不复制成互不相干的数据源；任何上游修改都会使相关下游结果失效。

## 寻峰与峰参数
原始计数不覆盖。奇数窗口移动平均后识别局部极大值，用有限邻域局部突出度及最小峰距筛选。默认弱峰模式不再把全谱最高峰作为统一门槛，而计算 `S = 局部突出度 / sqrt(max(1, 局部本底/平滑窗口))`，默认保留 S≥4 的候选；旧版全谱比例模式仍可切换作对照。该式是局部泊松噪声假设下的工程筛查统计量，不是 p 值，也没有校正多重比较。
宽度为平滑谱局部半突出度宽度，仅作孤立峰 FWHM 初估。ROI 依据该宽度选择；峰高取原始计数；净面积为原始计数减 ROI 两端连线本底的有符号逐通道和，不将负残差截零。质心使用正残差权重，仍存在估计偏差。
默认结果不是Gaussian拟合或探测器分辨率测量；未评定统计不确定度。可选的双Gaussian实验模式仅对已经寻得且距离小于约1.75倍局部宽度的相邻峰拟合两个Gaussian加线性本底，使用有界网格搜索质心/宽度并在线性子问题中估计本底和非负峰高。它输出收敛标记、RMSE、分峰面积和FWHM，但没有协方差时不能报告参数不确定度，也不会强行拆分单个宽峰。复杂本底、拖尾和更高重数峰仍会偏差。间断通道禁止寻峰。
局部突出度的定义参考 [SciPy find_peaks](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.find_peaks.html)。弱峰改进的研究依据包括 Morháč 等的 [非线性峰剥离本底估计](https://doi.org/10.1016/S0168-9002(97)01023-1)、Morháč 与 Matoušek 的 [SNIP 本底算法](https://doi.org/10.1366/000370208783412762)，以及 γ 谱弱峰的小波/连续小波研究（[Yu 等，2008](https://doi.org/10.7538/yzk.2008.42.11.0984)；[Xiong 等，2014](https://doi.org/10.4028/www.scientific.net/AMM.672-674.1911)）。实验SNIP模式实现LLS压缩、递减二阶裁剪窗口及逆变换；标准谱结果表明8σ能降低候选数量并保留多数主要线，但Eu-152的1089.737 keV弱线未达到该阈值，所以它不替换默认模式。

## 标定
用户参考点普通最小二乘 E=aC+b；至少两个不同通道、有限正斜率。输出残差、RMSE、R²。两点零 RMSE 不证明准确，也不校正漂移或非线性。不从文件名猜标定；合成谱 E=C 仅用于算法验证。

自动建议仅适用于用户已经知道标准源核素的场景：先从当前共享谱寻峰，再将最显著峰与该核素的强参考线按能量顺序组合，选择预拟合结果并填入文本框。程序不会自动应用，用户必须检查峰形、参考线和实验记录后确认。未知谱只凭两条峰线存在无穷多组线性映射，因此不提供“自动猜核素并标定”。已知 Na-22 标准源可使用 511 keV 湮没线作能量参考，但该线不能支持唯一核素识别。

## 核素证据
按绝对能量容差查固定数据，以残差与伴随峰支持评分并保留 Top-N。评分不是概率。
supported 为伴随峰支持；tentative 为暂定；conflicting 为容差边缘且支持不足；insufficient_evidence 为证据不足。所有等级均非确认检出。
伴随峰区分 found、not_observed_not_excluded、outside_range。观测峰不能自我支持，也不能重复作多条伴随证据；511 keV 湮没线不能提供唯一核素结论。未纳入效率、几何、自吸收、样品组成、照射/冷却与反应截面。

## 状态与报告
手动与助手共用 Workspace，新文件或参数变动使相关结果失效。JSON 保存原始谱、字节 SHA-256、配置、结果和证据；HTML 输出完整原始谱与同一快照。
离线规则助手不是大模型。统一模型适配层支持 Ollama、OpenAI-compatible、Anthropic 与 Gemini；密钥仅由服务端环境变量读取。模型仅返回白名单操作，科学数据仍由本地工具提供。手动入口可验证任意真实模型输出，但不认证来源；自动 API 与手动粘贴在审计记录中分开标记。可靠性说明为固定证据解释，不是自由模型推理或计量学确认。
